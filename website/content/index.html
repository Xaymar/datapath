Local IPC for C++11 and newer, C, Rust, Python and Node.js

Message passing with a predictable worst case.

DataPath moves whole messages between processes on the same machine, from a few bytes to many megabytes. It is built for the one round trip in a thousand that other libraries leave to chance: measured at p99.9, at the worst CPU placement, with every core busy.

Small library, sharp edges filed off

No dependencies beyond the C++ standard library and the operating system. One API on every platform.

No timers on the data path

I/O threads busy-poll for 50 µs after the last event, then sleep in the kernel at raised priority. Zero-copy receive, several small messages per system call.

Shared memory by default

On Windows and Linux messages move through two rings mapped only by the two processes; the pipe or socket carries just the handshake. Handlers get a private copy a hostile peer can't change.

Whole messages

Each send() arrives as one on_message call. Messages from different threads never interleave. One server, any number of clients.

Explicit backpressure

send() never blocks and never grows without limit: it returns TooLarge or WouldBlock, and a message is queued whole or not at all.

Safe setup and teardown

User, group or world access control, a version handshake and peer validation before on_accept. Destroying a handle waits for running handlers.

Native transports

Named pipes with I/O completion ports on Windows, Unix domain sockets with epoll on Linux and kqueue on macOS. A peer without shared memory still connects.

An echo server in a dozen lines

Host a server, accept clients, reply from the handler. send() is thread-safe and safe to call from handlers.

#include <datapath/datapath.hpp>

// Server
std::shared_ptr<datapath::server> server;
datapath::host(server, "my-service");          // a named pipe or abstract socket
server->on_accept([&](std::shared_ptr<datapath::socket> client) {
    datapath::socket* raw = client.get();      // don't capture the shared_ptr in its own handler
    client->on_message([raw](const uint8_t* data, size_t size) {
        raw->send(data, size);                 // echo
    });
    clients.push_back(client);                 // keep it, or the connection closes
    return true;                               // false rejects the client
});

// Client
std::shared_ptr<datapath::socket> sock;
if (datapath::connect(sock, "my-service") == datapath::error::Success) {
    sock->on_message([](const uint8_t* data, size_t size) { /* data valid during the call */ });
    sock->send("hello", 5);
}
