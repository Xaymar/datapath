6//! Native Rust core of DataPath.
7//!
8//! This crate is being built up in phases (see the migration plan): the
9//! platform-free parts come first, then the POSIX and Windows backends, then the
10//! C ABI and the language bindings. Until the switch-over it lives beside the
11//! C++ core and is not published.
12//!
13//! * [`error`]: the error codes shared with the C API.
14//! * [`proto`]: the wire format (frame header, handshake, incremental frame parser).
15//! * [`queue`]: the bounded, coalescing, multi-producer send queue.
16//! * [`spin`]: busy-poll for a short budget, then block.
17//! * [`options`], [`conn`]: settings and the platform-neutral connection state machine.
18//! * `api`: contexts, sockets and servers, on Linux, Android and macOS so far.
19//!
20//! The platform-free modules do no I/O and need no `unsafe`. The backend under
21//! `sys` is built on `rustix` and is safe code too, except for three small
22//! spots on macOS where `rustix` has no wrapper (kqueue's `kevent`, the
23//! quality-of-service call, and `sysctlbyname`), each a single FFI call.
24
