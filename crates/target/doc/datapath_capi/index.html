The C ABI of DataPath, implemented over the native Rust core.

The functions, structs and constants here are the ones declared in include/datapath/datapath.h (C ABI version 1), which stays the header of record: a binary built against it links against this library unchanged. The conventions are those of that header: opaque handles, error codes with out-parameters left untouched on failure, callbacks that receive a user pointer and an optional user_free, size-tagged option structs.
